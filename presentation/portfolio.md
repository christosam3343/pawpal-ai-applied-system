# Portfolio entry

**Project description**  
PawPal+ AI extends a Python and Streamlit pet-care tracker into a daily planner with constraint-based schedule repair, local language-model support, and owner approval.

**Student reflection draft**  
This project shows how I think about giving an AI system a useful role with clear boundaries. I extended my earlier pet-care tracker so it could plan around real scheduling constraints like travel, a shared caregiver, and fixed medication reminders. I can explain where language interpretation ends, how Python verifies each proposal, and why approval checks the latest task data before changing recorded times. The reproducible examples let a reviewer see the system handle both a conflict it can repair and one it has to block.
