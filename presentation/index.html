Module 2 PawPal+

  • Multiple pet profiles and recurring tasks
  • Manually recorded times and overlap warnings

Applied AI extension

  • Account for travel and fixed care times
  • Find and verify a feasible daily plan
  • Apply changes after owner review

Planning and approval

1. Collect constraints

Streamlit snapshots a day of tasks, priorities, availability and appointment travel.

2. Build the first draft

Recorded times anchor the draft. Optional local Qwen interprets a soft timing preference for untimed tasks.

3. Check and revise

Python validates the draft. CP-SAT searches for a revision when it finds conflicts, then the validator checks again.

4. Ask the owner

The owner reviews the proposal and decides. Approval checks the latest task data before applying.

Limits and lessons

  • One caregiver, one day, and manually entered travel estimates.
  • The language model can misread a goal. The owner can select a timing preference directly.
  • Approval rechecks constraints because a task may change after the proposal is made.
